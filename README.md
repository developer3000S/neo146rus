## О проекте

**neo146** предоставляет минималистичный (и экспериментальный!) информационный шлюз, который служит методом экстренного сетевого подключения, вдохновленным эпохой dial-up, позволяя получать доступ к контенту через определенные протоколы. Текущие реализации — шлюз HTTP-SMS и шлюз HTTP-Markdown.

Название **«neo146»** происходит от исторической турецкой общественной службы коммутируемого доступа (dial-up), которая работала по номеру 146. Этот проект был создан за несколько дней для поддержки протестующих во время восстания 19 марта 2025 года в Турции, последовавшего за арестом мэра Стамбула Экрема Имамоглу, кандидата в президенты от оппозиции.

Сервис бесплатный, но его содержание обходится примерно в 20 евро в месяц, а также от 5 до 20 центов за сообщение для SMS-шлюза; пожалуйста, используйте его ответственно. Чтобы поддержать сервис и получить лучший опыт использования, пожалуйста, рассмотрите возможность пожертвования и подписки.

SMS-ответы кодируются в base64 для экономии SMS-кредитов. Для отправки длинных ответов используется несколько сообщений, последовательность которых указывается в ответе префиксом `GW<номер>|`.

HTTP-ответы по умолчанию не кодируются, но их можно запросить с параметром `b64=true`.

```
+-------------------+
| +90 850 242 0 146 |
+-------------------+
```

## Доступные команды

### SMS-команды
*   `URL (https://...)` — Загрузить и преобразовать любую веб-страницу в формат Markdown
*   `twitter user <username>` — Получить последние 5 твитов пользователя Twitter
*   `websearch <query>` — Поиск в Интернете через DuckDuckGo
*   `wiki <2charlangcode> <query>` — Получить краткое содержание статьи из Википедии
*   `weather <location>` — Получить прогноз погоды для указанного места

### Команды Telegram-бота
*   `/url <url>` — Преобразовать веб-страницу в формат Markdown
*   `/twitter <username>` — Получить последние 5 твитов пользователя Twitter
*   `/search <query>` — Поиск в Интернете через DuckDuckGo
*   `/wiki <lang> <query>` — Получить краткое содержание статьи из Википедии
*   `/weather <location>` — Получить прогноз погоды для указанного места
*   `/subscribe <email>` — Подписаться на сервис
*   `/help` — Показать доступные команды

## HTTP-эндпоинты

*   `/uri2md?uri=<uri>[&b64=true]` — Преобразовать URI в Markdown
*   `/twitter?user=<user>[&b64=true]` — Получить последние 5 твитов пользователя
*   `/ddg?q=<query>[&b64=true]` — Поиск в Интернете через DuckDuckGo
*   `/wiki?lang=<2charlangcode>&q=<query>[&b64=true]` — Получить краткое содержание статьи Википедии
*   `/weather?loc=<location>` — Получить прогноз погоды
